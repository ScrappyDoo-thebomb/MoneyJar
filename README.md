# MoneyJar

An interactive savings jar game with a **$15,000** goal.

- Drop money in using $5, $10, $20, $50 and $100 bills, or any other whole amount of $5 or more.
- The jar fills up as you save, and each bill falls onto the pile.
- At the end of every calendar month, a line is **engraved on the glass** at the total you had saved by that month's last day, labeled with the month and amount.
- See your average per month, a projected finish date, and milestone alerts at $1k, $2.5k, $5k, $7.5k, $10k, $12.5k and $15k.
- Backdate deposits with the date picker, undo or remove deposits, and copy or restore a backup code.

## Run it

Open `index.html` in a browser. Your progress is saved in that browser's local storage, so use the backup code to move it to another device.
